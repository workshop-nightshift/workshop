how to write the list

A line can start with a date: 2026-12-21, Dec 21, 21 December, 21st Dec 2026. Add a range with a dash: Dec 24–26. Anything after the date is what goes on the day.

Lines without a date are laid out in order from the start date, one per day or one per week — good for a thirty-day list of anything. Start a line with * to ring the day. Blank lines and lines beginning with # are ignored.

Numeric dates like 3/4 are left alone, because half the world reads them one way and half the other. Nothing you type leaves this page; the list is kept only in this browser.
