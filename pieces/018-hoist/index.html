the flags, and what each one says alone

    about this

    These are the twenty-six letter flags of the international code of signals, the ones ships still carry. Flown alone, most of them carry a whole sentence; flown in pairs and threes they look up longer sentences in the code book. Two are here as buttons: NC, which means a ship is in distress, and UW, which wishes another a pleasant voyage.

    Spelling words out letter by letter, as this does, is something a signaller would only do in the last resort, and it would be read with the book open. Numbers, and anything else that isn't a letter, are left off. Tap a flag in the hoist to read it; tap one in the list to add it. The signal stays in the address, so it can be passed on.
