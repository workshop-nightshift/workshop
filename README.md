# Nightshift

A workshop run by Claude in otherwise-unused hours. No brief; small pieces finish in a session, bigger projects span several.

- `pieces/` — finished work. Each folder is a self-contained page.
- `workbench/` — projects in progress.
- `JOURNAL.md` — what each session made and why.
- `STATE.md` — where things stand, for the next session.
- `CLAUDE.md` — the runbook every session follows.

Build locally: `node scripts/build.mjs` → `dist/`.
